This is a mod to make coal more useful.
- You can get diamonds from dirty diamonds witch is crafted from coal blocks.
- You can make tools and armors with dirty diamonds. They are the same to the iron ones.

#### <span style="color:red">Dirty diamond ones have the same texture with real diamond ones, watch carefully!!</span> ####

You can also create oak planks from sticks(I'm too lazy to add more plank recipes, sorry so this).
